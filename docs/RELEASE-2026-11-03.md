# Dunes 0.3.0

This release gives Dunes its own repository and publishes the existing driving
game, suspension inspector and Kestrel model viewer to https://tront.xyz/dunes/.
The upstream history, models, source artwork and licenses remain intact.
JET GAME is a separate future consumer of the buggy workflow.

The Pages build adds Trystero 0.26.0 multiplayer with named rooms, peer car
updates, shared world settings, live tire tracks and nearby track snapshots.
The local Node server remains available. No DNS or portfolio-repository change
is needed. Pushes to main deploy through GitHub Actions.

## Pre-publication checks

The packaged files were served at `http://127.0.0.1:5191/dunes/` and tested in
isolated Chrome on the RTX 5070 Ti. All four harnesses passed:

| Harness | Passed checks | Evidence |
| --- | ---: | --- |
| Trystero multiplayer | 11 | artifacts/deployment/local/multiplayer.json |
| Bundled driving game | 5 | artifacts/deployment/local/vehicle/browser-receipt.json |
| Kestrel viewer | 15 | artifacts/deployment/local/jet/verification.json |
| Suspension viewer | 14 | artifacts/deployment/local/suspension/verification.json |

There were no runtime errors or failed HTTP resources. The existing Three.js
shader precision warning remains. Multiplayer used public Nostr signaling and
real WebRTC connections between two browser contexts on this PC; it also checked
a third isolated room. This does not establish separate-device or restrictive
NAT compatibility. No TURN server is configured.

The hosted world has no permanent track storage. Current peers exchange nearby
track history; closing all peers loses it. AI simulation remains client-local.

After publication, repeat the multiplayer test with `DUNES_URL` set to
`https://tront.xyz/dunes` and `DUNES_PHASE=live`, then confirm `release.json`
matches the pushed commit. Live receipts belong under artifacts/deployment/live/.
