# GLX sandrail textures

Every image here is painted procedurally with Python, PIL and numpy. Nothing was downloaded.
The reference photos in `ref/` were used only to measure the layout. To regenerate:

    python textures/generate.py                 # everything (~4 min)
    python textures/generate.py livery screens  # some groups only

Groups: `carbon carbon_interior livery livery_top hex_mesh floor_mat door_quilt seat firewall screens lights tires`.
Mirror reflections are rendered, not painted: `textures/bake_mirror.py --blend out/part_textures_all.blend`
(Cycles, from a full-car build; see the Mirrors table).
Sources: `generate.py` (entry point), `texlib.py` (noise, twill weave, normal maps, GLX wordmark),
`livery_paint.py` (body livery), `livery_data.py` (measured band outlines), `interior_paint.py` (trim), `gauges_paint.py` (screens, LEDs, tyres).

Conventions:
- Colour maps are sRGB. `*_normal.png` are tangent-space normal maps in the OpenGL convention
  (green = +V up), loaded as Non-Color.
- Image row 0 is UV v = 1, so the top of the image is +V.
- Livery orange is `#ff5a0d` (spec.COLORS['orange']). Stitching is `#ff6a1a`.

## Tyres

| file | size | what / how to map |
|---|---|---|
| `tire_front_sidewall.png` / `_normal.png` | 2048x256 | Front rib tyre sidewall: raised "GLAMIS TIRE CO  RIDGE CUTTER" plus small print, twice around, and moulded rings. |
| `tire_rear_sidewall.png` / `_normal.png` | 2048x256 | Rear paddle sidewall: "GLAMIS TIRE CO  DUNE PADDLE  35x15" plus small print, twice around. |

For both tyre strips, u wraps once around the tyre (seamless in u). v = 0 is the rim bead (bottom row) and v = 1 is the shoulder (top row), and the letters stand upright with their tops toward the shoulder. Suggested mapping on the outer sidewall: u = angle / 2pi, v = (r - r_bead) / (r_shoulder - r_bead). On wheels whose outer face points to -x, flip u so the text still reads clockwise.
