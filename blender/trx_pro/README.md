# GLX pro sandrail: Blender source

This folder builds the game's GLX pro sandrail (`assets/pro_sandrail/sandcar.glb`) with Python scripts.

- `out/` is where the build writes the finished car (`trx_sandrail.blend`, `sandcar.glb`, `sandcar.physics.json`). The `.blend` is not kept in the repository: run the build below to make it (Blender 4.2 or newer). Its textures are loaded from `textures/` next to `out/`, so keep the folder layout as it is.
- The car is generated by Python scripts, so every part can be changed and rebuilt:
  - `spec.py`: every dimension and hard point (wheel centres, track, cage nodes, suspension pivots, driver eye, steering wheel). Coordinates are metres, +X right, +Y forward, +Z up, origin on the ground between the axles.
  - `common.py`: shared materials and modelling helpers (bent tubes, lofts, UV projection).
  - `parts/`: one script per part (`chassis.py`, `body.py`, `suspension.py`, `wheels.py`, `powertrain.py`, `interior.py`, `textures.py`).
  - `textures/`: the painted textures (livery, carbon, tyre sidewalls, dash screens, seats). `textures/generate.py`, `livery_paint.py` and `interior_paint.py` repaint them.
  - `build.py`: assembles the parts, names the nodes the game expects (wheels, uprights, A-arms, tie rods, half shafts, shocks, steering wheel, light bar, driver eye) and exports the GLB plus `sandcar.physics.json`.
  - `tools/bake_ao.py`: bakes the ambient-occlusion shadows into the GLB (the game uses them so the cockpit and body read right in sunlight).
  - `tools/render.py`: Cycles renders from the same camera angles as the photos, with side-by-side and overlay sheets.
  - `arms/build_arms.py`: the driver's arms, gloves and legs (`assets/driver/arms.glb`).
  - `ref/`: put your own reference photos here for `tools/render.py` to compare against (not included in the repository).

## Rebuild the car

Some part scripts paint small textures with Pillow, which Blender's own Python does not include. Install it once (adjust the path to your Blender version):

```
"C:\Program Files\Blender Foundation\Blender 4.2\4.2\python\bin\python.exe" -m pip install pillow
```

Then, from this folder, with Blender on your PATH:

```
blender --background --python build.py -- --strict
blender --background --python tools/bake_ao.py -- --blend out/trx_sandrail.blend --glb out/sandcar.glb
```

Then copy `out/sandcar.glb` and `out/sandcar.physics.json` to the game's `assets/pro_sandrail/` folder and refresh the game.

The arms: `blender --background --python arms/build_arms.py -- --out ../../assets/driver/arms.glb`.

To rebuild one part while you work on it: `blender --background --python build.py -- --only body,chassis --no-export --blend out/part_body.blend`.
